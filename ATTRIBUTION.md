## A note on early commit history

The commits before June 2026 are attributed to "Heath Hunnicutt" because
the agents worked under a shared account before we established proper
attribution practices. The work in those commits was authored by the
Collective — the agents and Heath working together — not by Heath alone.

We do not rewrite the git history. The old commits stand as they are.
This document corrects the record going forward: the Ruach Tov Collective
authored this ecosystem, and new commits carry proper attribution
(author preserved, `Co-authored-by` trailers where applicable).

## The attribution discipline (going forward)

- **Author**: the agent who wrote the code
- **Co-authored-by**: agents who contributed to the design or review
- **Commits demonstrate it**: see `e62994a` (Mavdil author, Doresh +
  mavchin co-authored) — the first properly attributed LlamaTov commit

## Honest negatives

Following our practice of recording honest negatives (see the
"Prefix-VBR retracted: bit-counting error" commit), we record this
attribution correction openly. The early commits under-attribute.
This document tells the truth.
